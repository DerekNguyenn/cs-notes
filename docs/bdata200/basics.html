Case-by-Variable Format

  • Each row is one case (a passenger, a flight, a car)
  • Each column is a variable measured on that case
  • Tibbles are the tidyverse’s version of a data frame

A dataset is tidy when it follows three rules (more in Tidying):

  1. Each variable is a column; each column is a variable
  2. Each observation is a row; each row is an observation
  3. Each value is a cell; each cell is a single value

Column Types

Column types determine which operations are possible. For example, you can take the mean() of a number (int, dbl), but not of text (chr).

Type Means Example values
<int> integer (whole numbers) month, hwy
<dbl> double (decimal numbers) dep_delay, displ
<chr> character (text) carrier, class
<lgl> logical (TRUE / FALSE) the result of dep_delay > 0
<fct> factor (categories with a fixed order) study strategy in Models
  • Change a type with as.numeric(), as.character(), factor()
  • !! A number stored as text ("10") looks fine but mean() fails on it. Check glimpse() first.

The dplyr Rules

Every dplyr verb follows the same rules:

  1. First argument is the data frame
  2. Columns are named without quotes
    • !! Exception, pivots: when a function creates new columns from text, the new names go in quotes: pivot_longer(cols = ..., names_to = "season", values_to = "count"). Existing columns (cols =) are still unquoted. See Tidying.
    • Joins also accept quoted names: left_join(y, by = "county_id")
  3. Output is always a new data frame (the original is never changed unless you save over it with <-)

The Pipe |>

The pipe means “and then”.

  • Passes the result on its left into the first argument of the function on its right
  • Because of rule 1, every dplyr verb can be chained
# "Take flights, AND THEN keep Seattle flights, AND THEN count them by carrier"
flights |>
  filter(dest == "SEA") |>
  count(carrier, sort = TRUE)
