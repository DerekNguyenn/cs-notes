Reflection & To-do

Notes #2 Reflection

  1. What topics or concepts have been the most trouble since Notes #1?

    I think one of the more notable topics introduced between Notes #1 and now was the section on joins. I can definitely see how incredibly useful they are when you’re working with multiple data sets, which is why it’s taken me more time to wrap my head around this concept. I think I did a pretty good job with my notes on joins, but I do want to start using it more on projects or activities to help me solidify my understanding.


    Day 6’s class activity on cleaning up data was also really informative. In a perfect world, data comes out squeaky clean and we can jump straight to analysis, right? I actually found myself enjoying the puzzle solving nature of how to tidy up a data set. Although we didn’t get around to doing a code implementation, it was still pretty fun planning out a procedure in pseudocode.

  2. Did a mistake in HW1 or class show up again later? How was it addressed?

    I wouldn’t call this a “mistake,” but I still tend to forget how useful some functions and operators are in R. For example:

    • The combination c() function to store multiple values as a vector.

    • The %in% to search in a vector, as opposed to writing multiple conditionals.

    • Storing stuff in variables. It’s a bit ironic since you do this a lot in other programming languages, but I haven’t made it in a habit in R (besides storing new datasets, of course).

    These haven’t been addressed yet, but they’re going into my to-do list for the next notes update.

  3. What has helped most since Notes #1?

    …This site (lol). No, seriously, finally setting aside time to figure out how to make a site built on Quarto documents has been immensely helpful for my learning in this class and outside with my own personal projects! Splitting my master document into multiple documents was a chore, but I really like the current workflow I have for adding new content going forward. The site looks really clean — it reminds me of the R for Data Science layout with the added benefit that these are still my personalized notes, so I know how to navigate quickly!

  4. Feedback for Dr. Lisinker

    As we approach the halfway mark this quarter, I can feel things picking up and I am pretty excited about finally getting to lay out the foundations for my data story project. I do not have any notable comments or concerns I want to bring to your attention at this time. Thank you for prefixing the activities with the class sections! I also liked the new changes you made to the Canvas modules page.

    I’ll be honest, some readings (like anything from the IMS textbook) are pretty dense, but I do like the current format we have with the activities. For example, Day 9’s introduction to study designs was helpful. Reading the textbook and jotting down definitions is one thing, but identifying each designs’ strengths and limitations under real-life scenarios really helped solidify my understanding.
